# Backblaze

> Backblaze is a cloud storage and data-backup provider. Its B2 Cloud Storage is a low-cost, S3-compatible object-storage service exposed through two APIs: the B2 Native API (JSON over HTTPS, token auth via b2_authorize_account) and an S3-Compatible API (AWS Signature V4). This file is generated by API Evangelist from the apis.io catalog entry for Backblaze; it links the human docs and the machine-readable API artifacts we maintain.

## APIs
- [Backblaze B2 Cloud Storage API (B2 Native)](https://www.backblaze.com/apidocs/introduction-to-the-b2-native-api): Account authorization, buckets, files, large-file multipart upload, application keys, lifecycle, replication, and event notifications. Current version v4.
- [Backblaze S3-Compatible API](https://www.backblaze.com/apidocs/introduction-to-the-s3-compatible-api): Drop-in S3 endpoint (s3.<region>.backblazeb2.com) for existing S3 tooling.
